# Phase 5: Professional UI/UX Redesign — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Fix theme-breaking hardcoded colors in messaging/reports, add a global toast system, add empty states + loading indicators, and polish form UX — all without changing any functionality.

**Architecture:** CSS-first approach using existing CSS variable system (`var(--bg-card)`, `var(--text-body)`, `var(--border-card)`, `var(--text-muted)`, `var(--bg-input)`, `var(--border-input)`). All 10 dashboard themes inherit from these variables, so updating hardcoded hex values to CSS vars fixes every theme at once. The toast system is a lightweight React context + portal — no external libraries.

**Tech Stack:** React 18, plain CSS (no CSS-in-JS), existing CSS variable system already in `frontend/src/App.css`

**Worktree:** `.worktrees/phase5-ui` on branch `phase5-ui`

## Global Constraints

- **No external libraries.** All changes use plain CSS + React hooks. No import of any new npm package.
- **No functionality changes.** Phase 5 is styling and UX only. Do not change API calls, form logic, routing, state structure, or business rules.
- **CSS variables only.** All color values in `.msg-*`, `.rpt-*`, and chart components must use `var(--*)` tokens — no hardcoded hex. The existing CSS var names are: `--bg-body`, `--bg-card`, `--bg-sidebar`, `--text-body`, `--text-muted`, `--bg-input`, `--border-card`, `--border-input`.
- **Rules of Hooks.** Never call any hook inside a conditional, loop, or IIFE render block.
- **Files to touch:** `frontend/src/App.jsx` (lines ~1137–1196 for charts; ~1340–1380 for new toast state; ~1525–1935 for useEffect/render sections) and `frontend/src/App.css` (lines ~5049–5105 for `.msg-*` and `.rpt-*`).
- **App.jsx is 9064 lines.** Always read the exact lines before editing. Never guess line numbers.
- **No new files.** Keep everything in the existing two files.

// ===== TOAST SYSTEM =====
const ToastContext = React.createContext(null)
function useToast() { return React.useContext(ToastContext) }
function ToastProvider({ children }) {
  const [toasts, setToasts] = React.useState([])
  const toast = React.useCallback((message, type = 'success') => {
    const id = Date.now() + Math.random()
    setToasts(prev => [...prev, { id, message, type }])
    setTimeout(() => setToasts(prev => prev.filter(t => t.id !== id)), 3500)
  }, [])
  return (
    <ToastContext.Provider value={{ toast }}>
      {children}
      <div className="toast-container">
        {toasts.map(t => (
          <div key={t.id} className={`toast toast-${t.type}`}>
            <span className="toast-icon">{t.type === 'success' ? '✓' : '✕'}</span>
            <span className="toast-msg">{t.message}</span>
          </div>
        ))}
      </div>
    </ToastContext.Provider>
  )
}
```

  }
  setDonationSubmitting(true)
  try {
    const res = await fetch(`${API}/dons/`, { ... })
    if (res.status === 401) { onLogout(); return }
    if (res.ok) {
      const created = await res.json()
      setDonations(prev => [created, ...prev])
      setDonationForm({ donation_type: 'financier', amount: '', currency: 'USD', orphanage: '' })
      toast('Don enregistré avec succès.', 'success')
    } else {
      const err = await res.json().catch(() => ({}))
      toast(err.detail || "Erreur lors de l'enregistrement.", 'error')
    }
  } finally {
    setDonationSubmitting(false)
  }
}
```

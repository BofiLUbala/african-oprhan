# Prompt: De-Generic an Existing UI

For the "this was AI-generated and it shows" situation. Copy, fill, attach code, send.

---

Using the 21st-ui-design skill, redesign this UI so it stops looking generic/AI-generated, without changing what it does.

**What it is:** [product + surface]
**What's wrong (my words):** [e.g. "looks like every v0 output", "purple gradient soup", "no personality"]
**What must NOT change:** [content, structure, framework, specific components, brand colors if locked]
**Personality target:** [the one adjective it should own instead]
**Attached:** [current code / screenshots / tokens]

Work in this order:

1. **Diagnosis:** identify which specific AI-design tells from the skill's anti-pattern list this UI exhibits (name them by number/pattern, with locations). No generic commentary.
2. **Direction:** choose ONE style recipe that fits the product and my personality target. One-sentence rationale. This is the spine of every change that follows.
3. **Token transplant:** the new complete token set (oklch, light + dark) replacing the current values, with a short "was → now → why" note for the 5 most consequential swaps (e.g. "primary: generic blue 259° → terracotta 45° — counters category sameness, matches calm positioning").
4. **Structural fixes:** the layout-level changes — broken card-grid monotony, restored hierarchy, de-centered longform, CTA dominance — as a before/after list per section.
5. **Copy pass:** rewrite placeholder-flavored headlines/claims into product-specific ones (flag any facts you had to invent for me to verify).
6. **Rewritten code** for the affected components/sections, consuming the new tokens.
7. **Proof of change:** your anti-pattern re-review confirming the original tells are gone, plus the cover-the-logo verdict.

Constraint: minimum diff that achieves maximum de-genericization. Don't rewrite what already works — tell me what you deliberately left alone and why.

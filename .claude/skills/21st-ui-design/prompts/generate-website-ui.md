# Prompt: Generate a Full Website UI

Copy, fill the brackets, and send. Works with the `21st-ui-design` skill installed.

---

Using the 21st-ui-design skill, design and build a complete website UI.

**Product:** [name + one-sentence description]
**Audience:** [who, and what they feel before finding this product]
**Surface:** [landing page / full marketing site / app / storefront]
**Conversion goal:** [signup / demo / purchase / contact / credibility]
**Tone:** [3 adjectives max — e.g. "calm, credible, warm"]
**Stack:** [Next.js / React / Astro] + Tailwind [v3/v4] + shadcn/ui
**Constraints:** [existing brand colors/fonts if any; accessibility level; must-have sections]
**Explicitly avoid:** [e.g. "generic AI SaaS look", "anything resembling competitor X"]

Follow the full skill process:

1. State your product analysis and any assumptions (briefly).
2. Choose ONE style recipe from the skill and give a one-sentence rationale.
3. Output the complete token system: CSS variables (light AND dark, oklch), type scale, spacing rhythm, and 3–5 signature component rules that make this theme recognizably itself.
4. Break the page(s) down section by section, including drafted copy in the product's voice and mobile behavior per section.
5. Implement the components in [stack], consuming tokens only — no hardcoded colors.
6. Finish with your anti-pattern review: what you checked, what you changed, confirmation of CTA dominance and contrast in both modes.

If my brief is thin, make strong opinionated choices and flag them — do not ask me a questionnaire first.
